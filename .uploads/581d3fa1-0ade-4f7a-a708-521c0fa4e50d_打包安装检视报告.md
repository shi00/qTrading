### 1. P2｜应用自行退出后，崩溃恢复测试仍可能跳过强杀并通过

- **问题编号**：`PS-scripts.installer_smoke_crash_recovery / ENGA-CRASH-01`
- **代码位置**：[scripts\installer_smoke_crash_recovery.ps1](../../scripts/installer_smoke_crash_recovery.ps1)；[主流程 STEP 6](../../scripts/installer_smoke_crash_recovery.ps1)。
- **哪里有问题**：哨兵提交后、STEP 6 前主进程自行正常退出时，`if ($proc -and -not $proc.HasExited)` 不进入强杀，且没有 else 失败。随后正常退出的 sidecar/PG 满足无残留断言，重启读回也可以成功，脚本仍报告“崩溃恢复通过”。
- **造成什么影响**：正常关闭的持久性可能被当作强杀故障注入证据；不是已经证实产品崩溃恢复错误。
- **原因**：未把“强杀本次启动的、仍存活的主进程”设为必达前置与完成判据。

**具体怎么改**

仅在本脚本中，强杀前断言 `$proc` 非空且未退出；强杀异常必须传播；记录本次注入完成标记并在成功出口断言。接口影响：保持真实认证哨兵与 0/1 CLI 契约，不引入运行时业务依赖。边界验证：检查提交后自行退出、强杀失败、PID 变化、真正强杀成功四条路径；前三者不得通过。并发退出仍应失败，不能把自然退出补判为崩溃。

  替换 STEP 6 的可跳过 if 分支；最后一行放到 PASSED 输出之前，其间保留现有等待、重启和哨兵验证：

```
$crashInjected = $false
Assert-True ($null -ne $proc) "Crash target is the process started by this script"
Assert-True (-not $proc.HasExited) "Crash target is still running before injection"
Stop-Process -Id $proc.Id -Force -ErrorAction Stop
$crashInjected = $true
Write-Ok "Main process killed (PID: $($proc.Id))"

# 放在既有重启/哨兵断言之后、PASSED 输出之前。
Assert-True $crashInjected "Force-kill injection completed"
```

  兼容说明：复用本文件 Assert-True/Write-Ok、同一 proc 与原 0/1 出口；只禁止自然退出被当作已注入。强杀竞态异常传播到既有 catch，不能设为注入成功；未提供其他进程或 sidecar 实现的修改。

**如何验证**

前置条件：提交哨兵后替身主进程自然退出；操作：执行 STEP 6；预期结果：非零且不得输出 PASSED。另保留真实强杀、无孤儿、端口重读及哨兵相等回归。全部未运行，受只读边界限制。

### 2. P2｜任意安装失败都可能被误当作运行中拒绝升级

- **问题编号**：`PS-scripts.installer_smoke_running_app / ENGA-RUNNING-01`
- **代码位置**：[scripts\installer_smoke_running_app.ps1](../../scripts/installer_smoke_running_app.ps1)；[主流程 STEP 4、STEP 7](../../scripts/installer_smoke_running_app.ps1)的 `installExitCode -ne 0` / `installExitCode2 -ne 0`。
- **哪里有问题**：第一次安装已成功，但再次安装因磁盘、权限或其他安装内部故障返回非零，同时被测 PID 保持运行，即可满足全部“拒绝”断言；未检查退出来源为 InitializeSetup 运行中守卫。
- **造成什么影响**：运行中拦截功能被删除/失效，也可能被无关安装失败掩盖；不是已证实安装器当前存在该产品缺陷。

**具体怎么改**

### 3. P2｜使用固定临时文件名，下载前不移除既有文件，gh 返回码未检查，随后只检查 `Test-Path`

- **问题编号**：`PS-scripts.installer_smoke_upgrade / ENGA-UPGRADE-01`
- **代码位置**：[scripts\installer_smoke_upgrade.ps1](../../scripts/installer_smoke_upgrade.ps1)；[STEP 2 下载旧安装器](../../scripts/installer_smoke_upgrade.ps1)。
- **哪里有问题**：使用固定临时文件名，下载前不移除既有文件，gh 返回码未检查，随后只检查 `Test-Path`。在 usage 所示 Windows PowerShell 调用下，原生命令非零不由 ErrorActionPreference 自动变成终止异常；若文件早已存在，下载失败仍执行既有文件并继续升级测试。
- **造成什么影响**：网络/鉴权/资产匹配失败可被误当作指定旧版下载成功；现有文件内容未认证，最终“从 OldVersion 升级”证据失真。
- **原因**：将“路径存在”替代“本次下载成功且身份正确”。

**具体怎么改**

只改本脚本：下载到本次唯一目录，显式立即检查 LASTEXITCODE 与非空文件，再核验受信摘要/版本身份，失败不执行；finally 清理自己创建的文件。接口影响：保留 OldVariant 精确资产名与失败退出 1，不修改下载依赖或其他脚本。边界验证：验证旧缓存存在+下载失败、零字节、错误版本、成功下载、重复运行；缓存不得替代本次下载。摘要来源无法取得时明确失败/身份未验，不编造校验值。

  STEP 2 的本次下载与启动边界可采用下列片段；唯一 staging 位于当前工作目录，避免使用全局临时文件或拼入未校验参数作为本地文件名：

```
$downloadDir = Join-Path (Get-Location) ("installer-upgrade-" + [Guid]::NewGuid().ToString("N"))
New-Item -ItemType Directory -Path $downloadDir -ErrorAction Stop | Out-Null
$oldInstaller = Join-Path $downloadDir "old-installer.exe"
try {
    gh release download "v$OldVersion" --repo $env:GITHUB_REPOSITORY `
        --pattern "AStockScreener-Setup-$OldVariant.exe" `
        --output $oldInstaller 2>&1 | Out-Null
    $downloadExitCode = $LASTEXITCODE
    if ($downloadExitCode -ne 0) {
        throw "Old installer download failed (exit $downloadExitCode)"
    }
    if (-not (Test-Path -LiteralPath $oldInstaller -PathType Leaf)) {
        throw "Old installer was not produced by this download"
    }
    if ((Get-Item -LiteralPath $oldInstaller).Length -le 0) {
        throw "Old installer download is empty"
    }
    $oldInstallerProc = Start-Process -FilePath $oldInstaller `
        -ArgumentList '/SILENT', '/NORESTART' -PassThru -Wait
    Assert-True ($oldInstallerProc.ExitCode -eq 0) "Old version installer finished"
} finally {
    Remove-Item -LiteralPath $downloadDir -Recurse -Force -ErrorAction SilentlyContinue
}
```

  兼容说明：复用原 gh 下载参数、Start-Process/Assert-True 与 OldVersion/OldVariant，失败进入现有 catch 返回 1；旧缓存不再是本次成功证据。片段仅落实下载返回码、非空和唯一文件，不代表受信摘要/版本身份已验证。旧资产摘要格式、版本元数据契约未核实，仍待验证，不编造读取 API；正式身份校验须在启动前落实后才能宣称指定旧版已认证。

**如何验证**

前置条件：预留同名文件且替身 gh 返回非零；操作：下载；预期结果：不启动该文件、脚本失败。再测 successful-but-empty 与版本不符。未运行网络或安装器。

### 4. P2｜四方校验缺版本字段仍宣称通过

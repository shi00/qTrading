## 1. 设计目标与证据边界

用户在 QTrading 里研究股票，而不是管理 Agent。入口用“研究、比较、核对、继续”，默认不要求理解角色、DAG、MCP 或检查点。

验收覆盖全部既定需求与S00—S08旅程；页面和状态须真正串起操作，编号齐全不等于已实现，六项专项见§24.2。

导航/布局方向已确认，具体交互仍按本文验收；正式权限只由现行ADR裁决，原生门禁见[详细设计 §4](./AGENT_DETAILED_DESIGN_v1.4_2026-11-03.md#4-%E9%80%89%E5%9E%8B%E5%87%86%E5%85%A5%E8%AF%95%E9%AA%8C%E5%85%88%E5%8E%9F%E7%94%9F%E5%90%8E%E4%BA%A7%E5%93%81%E6%8E%A5%E7%BA%BF)。

### 1.2 必守约束

- 交互范式遵守 [UI/UX 规范](../../docs/flet/ui-ux-best-practices.md)、[无障碍基线](../../docs/flet/accessibility-baseline.md)、[Flet 项目差异](../../docs/flet/project-differences.md)。
- 后续实现采用[声明式 UI](../../docs/flet/v1-api-constraints.md)和 [MVVM](../../docs/patterns/mvvm.md)。View/VM 不拥有执行真相，切页/关面板不取消研究。
- 业务页直接分析、主会话研究、程序 API 共用能力，结果按原业务合约回原页面；新闻分类/情绪及 FinBERT 不因此全部 Agent 化。
- 子会话只读；必要决定全局可达；普通信息不抢焦点；原文、费用、资料时点和缺失状态真实保留。
- 当前权限仍以 [ADR-0008](../../docs/adr/0008-no-ai-execution.md)等现行约束为准。界面中出现工具、导出或批准按钮不等于相关能力已获准。

## 2. 信息架构方案与选择

采用完整研究工作区＋原业务页原位分析＋全局必要决定。保留现有外壳；任务和成果跟随主会话，资料/执行详情按需展开，不新增常驻助手侧栏或另造研究桌面。

## 3. 全局导航、状态和位置

### 3.1 导航提案

建议视觉顺序为“行情、自选、选股、回测、研究、任务、数据、设置”。保留原七项相对顺序、语义身份、深链和用户现场；新增研究是明确的产品增量，不冒称现有导航已经如此。

现有 Ctrl+1—Ctrl+7 的目标保持行情/自选/选股/回测/任务/数据/设置；提议 Ctrl+8 打开研究，tooltip 明示。不能直接把旧“序号＝导航索引”的实现套入新排列，否则 Ctrl+5 等会误跳；后续实现须改为明确目标映射并回归。现有 Ctrl+F 聚焦导航，不擅自改为聊天搜索。

研究入口显示运行/等待的真实计数；旧“任务”仍只表示原 TaskManager 任务。用户无需到任务中心操作 Agent。

### 3.2 全局状态区域

复用底部真实布局行，在外发提示旁增加“研究：1进行中 · 2待决定”文字入口。信息源错误显示“研究状态暂不可用”，不伪造0。普通完成/失败提醒可关闭并能定位主会话；必要决定不能只存在于 Toast。

待决定入口打开 P09；点击具体项进入 P08。关闭入口面板只影响观察。底栏不得覆盖结果表分页、输入框或导出反馈。

### 3.3 页面目录

P 编号是 UX 定位，不是要求新增24个独立 View、顶级路由或服务。

| 页面/界面 ID | 主要任务与入口 | 核心操作/输出 | 返回与状态归属 |
| --- | --- | --- | --- |
| P01 会话目录 | 从研究导航找/新建研究 | 最近、置顶、归档、搜索；重命名、受控删除 | 选中会话打开P02；目录本身不推理 |
| P02 主会话 | 表达目标、连续追问和推进工作 | 模式/模型、资料、消息、计划、任务、队列及成果入口 | 切页保草稿/选区/阅读位置；执行归应用服务 |
| P03 子会话 | 从任务卡查一项叶子工作 | 只读公开消息、工具、错误、来源/模型/轮次；查找复制 | 明确返回主会话；无输入、模型切换或直接控制 |
| P04 资料/证据面板 | 核对本次资料和引用 | 对象、版本、日期/as_of、范围、读取状态；发送前移除/选择 | 改活动输入走显式修订，不静默热改 |
| P05 计划审阅 | 从计划消息核对方案 | 目标/步骤/依赖/限制/预期成果、修订、明确版本启动 | 仅计划交付已结束；启动是新执行 |
| P06 成果预览 | 从会话或业务结果使用成果 | 类型化预览、证据定位、版本/差异、复制、导出 | 不改原业务数据；切回消息保现场 |
| P07 执行详情 | 查看总项/叶子状态和控制 | 单层树、依赖、轮次、阻塞、用量；从主会话控制 | 不把点击受理当控制已生效 |
| P08 必要决定框 | 任意页处理准确请求 | 授权/拒绝/稍后、澄清回答、方案选择 | 绑定来源/轮次/范围；安全交接旧Dialog |
| P09 待决定列表 | 从底栏/会话找回全部决定 | 来源筛选、期限/失效状态、逐项打开 | 串行处理，不叠框，不批准整批 |
| P10 历史搜索 | 关键词定位主子公开原文 | 中英文、标题/正文、角色/时间/状态/归档筛选 | 打开定位原消息；返回保搜索与滚动 |
| P11 修订/分支确认 | 从自己的旧消息或历史节点继续 | 原文/改文、上下文截点、范围、明确发送 | 排队修订另走P02队列；不迁移旧任务/审批 |
| P12 导出与结果 | 从已保存成果交付文件 | 版本/格式/路径/覆盖确认；失败、取消、需核实/重试 | 不重跑研究，研究与交付状态分开 |
| P13 删除影响确认 | 从会话目录或管理菜单清理 | 主子/副本/引用影响/残留说明及取消/删除 | 活动引用阻删；未知范围不放行 |
| P14 模型管理 | 从选择器跳现有AI大脑 | 现有连接/场景/用量与实际尝试明细 | 返回原草稿；不复制凭据或旧请求配置 |
| P15 角色/Prompt | 从研究设置配置默认能力 | 主/子角色引用、默认/自定义/有效合成、预览/保存/恢复、教程 | 生效范围明确，旧版本不覆写 |
| P16 Skills | 从研究设置管理或从“/”查看 | 导入、来源/许可、更新、启停、角色分配、卸载 | 活动绑定版本保留；安装不等于执行 |
| P17 MCP | 从研究设置配置工具连接 | 保存/启动/测试/鉴权/授权分别显示，工具来源可查 | 修改身份/schema复核；无自动授权 |
| P18 授权与外发范围 | 从设置、决定详情或用量入口核对 | 用途/目标/资料范围、有效期、查询/撤销、实际用量 | 复用既有治理；撤销不承诺收回已发送数据 |
| P19 业务原位分析 | 个股/选股已有分析入口 | 原页结果/错误/等待/执行记录、带上下文继续研究 | 保对象/请求/轮次，不暗建第二次分析 |
| P20 已有池候选研究 | 从明确选择的池/结果携带资料 | 条件核对，候选/不匹配/待核实与覆盖 | 需要重新筛选则回原模块，不暗扫描全市场 |
| P21 选定资讯研究 | 从已选新闻/公告或附件进入 | 事件/转载/观点/冲突/未知和时点 | 不默认采集或定时日报，不迁移固定分类链 |
| P22 已有回测解读 | 从选定已有结果进入 | 配置/口径/警告/可比性表和归因限制 | 不运行新回测、调参或改原报告 |
| P23 首用/帮助 | 空会话、缺配置、Prompt教程 | 四个目标示例、配置下一步、零修改使用指导 | Skills/MCP不是开始普通研究的前提 |
| P24 退出/重启回顾 | 应用关闭协调及重启后 | 未完成/需核实、可靠边界、明确继续或终止 | 观察恢复不派发，旧批准不复活 |

## 4. 研究工作区的布局

### 4.1 阅读顺序与低保真结构

```
QTrading导航 | 会话目录(可收起) | 会话标题 / 来源 / 搜索 / 更多
             | 新建 / 查找      | 紧凑总执行摘要（固定） -> 详情P07
             | 置顶 / 最近      | 本次模式、所选模型与配置来源
             | 归档入口         | 资料与截止日摘要 -> 展开P04
             |                  | ---------------------------------
             |                  | 用户目标、公开回复、必要工具摘要
             |                  | 单层任务卡、成果P06及来源入口
             |                  | [新消息，返回最新]（不强拉到底）
             |                  | ---------------------------------
             |                  | 当前任务补充/下一任务 及排队项
             |                  | 多行输入 / 附资料 / 选Skill / 发送
底部真实布局行：原外发提示 | 研究进行中/待决定入口
```

资料、执行详情、成果预览共用按需详情位置，一次主显示一种上下文，不再同时固定出三个右栏。子会话替换主内容区并显示“返回主会话”，不是弹出可输入的第二聊天。

### 4.2 宽度预算与窄窗

尺寸是原型验证目标，非已验证像素保证。沿用Flet默认断点；不得新增窗口resize监听链来实现另一套断点系统。

| 逻辑窗口宽度 | 内容布局 | 核心入口保留 |
| --- | --- | --- |
| 1024—1199 | 主内容单栏；会话目录/详情通过明确按钮打开有界面板或替换内容，不常驻挤宽 | 会话、资料、任务、成果、队列/待决定均有文字入口 |
| 1200—1399 | 主内容＋会话目录；打开详情时可收起目录改为主内容＋详情，保留目录返回入口 | 不叠四栏；关闭详情恢复原目录和位置 |
| ≥1400 | 可显示会话目录＋主内容＋按需详情；详情默认关闭 | 阅读正文不无限拉宽，数据表在内容区域内横向滚动 |

候选预算：会话目录220、详情300、主内容最低620，栏间距使用 `AppStyles.SPACING_MD`。按现有展开导航180、分隔1、正文左右各20估算，1400窗口正文约1179，三栏最低1164可容纳；1024正文约803，采用单栏。P04/P09在窗口宽度小于1200时覆盖模态显示；1200及以上关闭目录、为300宽侧详情预留空间，主阅读区不得小于620。不能另用1100阈值挤出侧栏；若实际可用宽度不足，仍须退回覆盖面板。实际长英文、缩放和滚动条仍须实测，不能缩字号或藏控制按钮。

正文阅读上限建议880，宽表可更宽。若这些值需进入实现，仅在主题中新增必要的语义宽度token，不在多个组件散落裸数值；本轮不修改主题。

### 4.3 高度、滚动与现场

- 在1024×640和1280×672下，标题/绑定摘要紧凑展示；任务细节默认收起，输入区适度增高后内部滚动，不让消息区消失。
- 消息、目录和详情各自滚动；页面主体不再包一个争夺滚轮的外层滚动。主要操作和输入不被底栏/Toast遮挡。
- 上滚阅读或选择文本时不自动追随输出；显示未读计数/返回最新按钮。焦点不随Token刷新移动。
- 以会话身份分别保存阅读位置、主草稿、资料选择、选中任务和详情；窗口重排、新建/切换会话或准备分支不清空原现场。
- 重启草稿采用已确认的[需求 DI-01](./AGENT_REQUIREMENTS_SCENARIO_v1.4_2026-11-03.md#162-%E7%A1%AE%E8%AE%A4%E6%B8%85%E5%8D%95)：自动仅在本机保存正文、模型/模式、手选 Skill 和资料身份/版本引用，不保存凭据值、额外文件副本或有效批准；焦点/选区不承诺跨重启恢复。引用失效明确提示；保存失败保留内存输入并在退出前说明，不把草稿记录当执行检查点或自动恢复许可。产品确认不等于重启恢复已经实现或验收。

## 5. 用户旅程到界面

| 场景 | 最短可用路径 | 用户成功/边界 |
| --- | --- | --- |
| S00 首次准备 | P23 → 引用已配置模型或P14 → P02 | 零自定义Prompt可开始；缺模型能查历史/教程，不强迫配置Skill/MCP |
| S01 快速理解 | P02直接提问 → 回复 → 追问/核对 | 不产生虚假计划/子任务；事实与一般解释分开；CQ04保原版和核实结果 |
| S02 业务分析 | P19原入口 → 原位结果/等待 → 查看执行或继续研究 | 打开记录不再提交分析；自由新问题才新意图；无聊天页也能处理P08 |
| S03 先计划 | P02选仅计划 → P05审阅/修订 → 明确版本启动 | 计划交付即结束，不永久占位；新启动走队列和新鲜核权 |
| S04 完整委托 | P20或P02明确对象/条件/时点 → 按需工作 → P06 | CQ01/CQ02区分完整、部分和未核验，候选不是买卖指令 |
| S05 带资料/资讯 | P04选资料 → P21/P02 → 来源核对/P06 | CQ03转载不当独立证据；局部读取/未知可见，拒绝外发无越权 |
| S06 已有回测 | P22选已有报告 → 对照表/告警 → 解释/P06 | CQ06只说明可支持的事实和假设，不能由收益更高断定策略更好 |
| S07 执行中参与 | P07看状态 → P08决定或P02补充/排队 → 明确控制 | 单叶/总项范围清楚；等待释放推理，兄弟可继续；控制受理与生效分开 |
| S08 回顾续研 | P10定位 → 原文/成果 → P11或明确新研究 → P06 | CQ05旧截止日补证与新时点研判分开；引用后删除遵P13，不自动写关注/方案 |

所有路径的结束都能回到原业务对象或主会话。自动回跳、切模型、重试、扩大资料范围和新执行不能由“返回/查看/复制”等观察动作触发。

## 6. 主会话：输入、模型、模式和资料

### 6.1 默认空态

标题“开始一项研究”，辅文“说明目标，按需选择资料；你始终保留最终判断”。示例入口：解释一个问题、核对已有候选、整理选定公告、解读已有回测。示例只填入草稿/准备资料，不直接发送，不承诺尚未获准的数据工具。

### 6.2 模型和模式

| 控件 | 默认呈现 | 生效规则 |

### 6.3 发送和多行编辑

- 输入框有持久label“研究目标或问题”，不能只靠placeholder；默认多行，提供发送按钮。
- 提案：Enter发送、Shift+Enter换行，帮助文字可见；中文IME正在组合/选字时Enter只完成输入，不提交。具体Flet事件实现须真实验证，不能靠模拟原型保证。
- 连续双击/重复Enter在同次提交身份下只受理一次；受理未知时显示“正在核对提交”，保留草稿和可查身份，不改键盲发。
- 明确受理后才把提交内容关联到对应队列/消息；本地草稿、已受理快照及实际执行版本分别显示，不以清空输入表示服务端已保存。
- 对正在工作的会话，输入区默认明确标“排队下一任务”，可显式切换“补充当前任务”并确认目标/范围，不由模型猜归属。无活动任务时只显示普通发送，避免所有小问题都要选任务归属。上述产品默认已获本轮确认，不追认旧S4形成时已有批准。
- 消息归属与草稿按会话/修订路径保存；查看资料、切页、切语言/主题或重绘不能把“补充当前”改成下一任务。发送按钮同步标“补充当前任务”或“排队发送”；可靠受理后新草稿恢复默认归属，未知或失败仍保原选择。新会话/新路径不继承另一现场的补充选择。
- 发送摘要显示本次沿用的消息修订路径和相关前序任务，不要求用户理解内部路径ID。查看旧历史不切换默认上下文；历史重发可靠受理后，即使仍排队，后续新输入沿新修订，旧队列保持原绑定。提交未知先核对，路径已变发生冲突时保留草稿并说明，不能静默换路。切页/重启只恢复现场，不自动执行。

## 8. 计划审阅与启动

P05显示目标/不做事项、资料/时点、步骤与依赖、预期成果、模型/能力来源、已知限制及版本。树表达主子隶属，依赖另行查看，不把缩进当DAG。

- 仅计划成果标“规划完成 · 执行未启动”，可继续讨论/修订/复制；不显示仍占位的运行旋转标。
- “启动计划 v3”明确具体版本及绑定范围；启动后生成新执行，同会话忙则排队。
- 计划被修订后的旧启动按钮失效；点击旧入口解释冲突并引导查看新版本，不偷偷启动最新版。
- 原资料/模型/窗口不可用时说明原因；变更后明确生成修订，不能用启动动作把旧快照换成当前选择。
- 执行模式里正在等待计划审阅，则标“当前执行等待审阅”，保留占位；不能与已交付的仅计划卡混为一谈。

## 9. 任务、子会话、进度与控制

### 9.1 单层任务与阅读

P02默认显示总任务阶段、完成/总叶数、真实阻塞和最近成果。展开P07看每项负责人、依赖、状态、模型/轮次、成果及错误；没有可靠分母时不显示伪百分比。

主会话仅保留一条紧凑的阶段、已完成工作数及“查看任务与控制”入口，不随消息滚走；完整模型、资料和任务细节不固定成多层工具栏。面向用户用“项工作”，内部“叶子”术语只在技术详情中解释。

点击叶子“查看记录”打开P03，顶栏显示“只读子会话 / 任务A / 轮次2 / 实际模型”。支持查找/局部复制，返回主会话不丢草稿。P03不出现输入框、改模型、编辑重发、分支执行或直接控制按钮；控制在主会话明确目标后进行。必要决定仍由全局框响应。

### 9.2 状态到界面动作

以下是产品呈现映射要求，实际原生状态字段与映射须后续冻结，不在UI再建执行状态机。E6的原生owner/session/child/run/generation/snapshot引用是执行身份，不等于界面所示逻辑attempt（轮次）；View只消费经核对的读模型，不根据cancel回执自行推断“已中断”。

| 可观察状态 | 主反馈 | 可用动作/禁止误导 |
| --- | --- | --- |
| 受理中/提交未知 | 正在提交/核对，不承诺已经入队 | 保留现场、查回；不换身份重发 |
| 已排队 | 原因、前方占位任务、绑定修订 | 编辑/撤回仅未开始项；另发明确新意图 |
| 准备派发/运行 | 当前阶段/公开操作摘要 | 中断/终止显示范围；不暗改输入 |
| 等依赖 | 指出前置和原因 | 无关分支继续；依赖失败不可冒充正在运行 |
| 等用户决定 | 待决定计数/定位入口 | P08允许拒绝/稍后；无UI不批准 |
| 中断中/终止中 | 已受理，正在等待安全边界 | 不立即显示已停止，不连续创建重复命令 |
| 已中断 | 现场和有效成果保留 | 明确继续/终止；占位不占推理 |
| 需核实 | 哪个提交/工具/保存/控制事实未知 | 只读核对/明确处理；不能以点击重试重复未知副作用 |
| 成功 | 有效必需工作及最终成果已完成 | 查看/复制/导出；观察不新执行 |
| 部分失败/失败 | 可用成果、未完成项、原因和后继未执行 | 合法精确重试新轮次；不重做仍有效兄弟成果 |
| 已终止 | 部分成果/旧记录/费用保留 | 明确重试才新执行；历史/重启/迟到事件不复活 |

### 9.3 危险操作和独立分支

总项和叶子操作分开命名：“中断整个研究”“中断任务A”“终止整个研究”。确认框说明影响范围、依赖、有效成果、未知外部事实以及“不是回滚”。可恢复中断不伪装成终态取消。

A等审批、B成功、D只依B、C依A/B时，界面必须看见D实际推进、C仍等A；不能仅把B标完成就称独立调度通过。重试A创建新轮次，旧A迟到只归旧记录。

E6原生cancel本身不是产品暂停，resume创建新的原生run。只有完整快照得到验证、重新核权并对账原run已发生工具副作用后，才可保留原逻辑轮次继续；否则显示需核实/阻断，不暗改成从头重试。ABCD依赖、独立控制与这一接续映射仍须原生实测，HTML的pause/resume模拟不提供该证据。

## 10. 全局必要决定与旧 Dialog 交接

### 10.1 P08 内容和操作

决定框按从上到下组织：标题/来源会话与任务/轮次；为何需要决定；工具及脱敏参数、目的地/资料范围/副作用或澄清问题；建议及影响；选项；操作区。技术详情可展开，但数据外发范围和危险影响不能藏起来。

| 决定类型 | 明确操作 | 不能发生 |
| --- | --- | --- |
| 工具/外发授权 | 允许本次明确范围、拒绝、稍后；可查看现有授权/撤销 | 安装/连接/选模型不当授权，不能笼统“一次允许所有资料” |
| 必要澄清 | 有label的答案/选项、提交回答、稍后 | 不用自由聊天绕开指定等待点，不猜缺参数 |
| 方案/计划选择 | 说明各选项影响，明确选择/稍后 | 未选择不能默选“建议方案” |
| 已失效请求 | 显示过期/撤销/改参/旧轮次/终止原因，可关闭定位 | 不保留仍可点击的批准按钮 |

关闭、Esc、超时、稍后均不批准；拒绝是有效决定，随后按真实可行路径继续或收敛，不伪装批准。

### 10.2 排队与焦点

- 全局一次只有一个可交互决定框。P09保留全部请求，逐项处理，不提供“批准全部”捷径。
- “稍后”暂缓当前已到达批次的连续弹出；底栏/会话入口仍醒目，切页/刷新不立即再次打断。新请求串行，但不抢正在输入的普通Dialog。
- 若已有设置/删除/导出Dialog在编辑，先提示有待决定并等待安全交接；记录原表单/焦点和输入代次，不能叠框让旧Enter/IME事件落到新批准。
- 授权不默认聚焦“允许”；旧表单按键不能批准。安全关闭决定后恢复原表单和合理焦点，不丢草稿。
- 回答提交后分别呈现“答复已记录”“已交付”“任务实际恢复”；未知先核对，同身份不重复消费。终止先于批准生效时显示失效，不复活任务。

## 11. 资料、来源与成果的可信呈现

### 11.1 P04 资料卡

每项资料有：来源/对象、版本或内容标识、发布时间/生效时间、研究截止日、实际读取范围和状态。状态包括未读取、读取中、已读取、部分读取、不支持、超限、过期、已变更、不可得、已删除；不能一律显示为绿色“已附加”。

支持范围按D06：TXT/Markdown/CSV/JSON/XLSX/文本PDF；PNG/JPEG受模型能力约束。扫描/加密PDF说明预处理；不暗转外部OCR、执行宏/外链/脚本。附件限制在选择前提示，超限后给分批/移除/预处理路径，不静默截断。

查看来源失败显示“引用存在，但原资料暂不可核对”，不自动搜索同名最新文件替代。只读预览不触发模型；需要继续研究才明确新请求。

成果中的来源入口须绑定准确身份/版本，打开P04后定位并展开对应原文及位置、发布时间和研究截止日；关闭回到原成果、阅读位置和引用入口。已删除、不支持或版本不可得时明示缺口，不展示另一版本的原文。离线原型仅提供CQ01的E-A1/E-B1/E-B2/E-C1/E-C2合成片段，并明确标注非真实文件/公告核验；其他资料的生产读取不因此通过。

### 11.2 P06 成果结构

共用“目标/时点/版本/完成范围＋主体内容＋证据/限制＋操作”结构，主体随类型变化，不把全部回答强制股票JSON。

| 成果类型 | 必须的语义 | 样例 |
| --- | --- | --- |
| 公司比较 | 对象、同期间/口径、单位、公式、证据及缺失 | CQ01缺丙资料不能删行或伪完整成功 |
| 候选核对 | 条件、覆盖、候选/不匹配/待核实分别计数 | CQ02无匹配不等于无数据，缺字段不填0 |
| 资讯归纳 | 事实、转载、观点、相关性、冲突、未知和时间线 | CQ03一个事件不能因转载成为双重验证 |
| 第二意见/纠错 | 原断言、核对依据、确认/争议、修订影响 | CQ04保R1/R2，未证实纠正不盲从 |
| 跨期续研 | 旧/新截止日、证据与判断差异、仍未知 | CQ05后来披露不回填原时点，修订不等同经营改善 |
| 回测解读 | 原报告值、区间/参数/成交成本/维度/告警、可比性与归因限制 | CQ06不以GOLD覆盖缺口，不由12%/20%断定策略更好 |

数值右对齐、单位和期间可见；未知/缺失与0区分。涨跌用业务色，执行状态用状态色，不用红绿承担唯一语义。来源可定位不代表事实必真，模型共识不代表投资判断正确。

成果首层展示结论、依据、缺口及人类可读的可核验状态；digest、内部可用性枚举和生成标识收进默认折叠的“版本与技术标识”。必要决定首层保来源会话、任务、轮次、状态和外发范围，内部session/request等身份默认折叠但仍可核对，不隐藏危险影响。

“复制摘要”只取当前选定成果及版本的公开内容，保留截止日、公式/来源、缺口和风险限制；子会话复制只取该轮公开核对摘要。不得按页面首个通用容器抓取模拟读取按钮、其他成果或设置文字；摘要不可得明确报错，不用标题伪装复制成功。

CQ01 的净利率和现金净利比均须独立可见，不能以“用户可从原值算出”省略。预览、持久成果读取和适用导出使用同一选定版本的字段契约，详细列与样例见 §24.2；当前页面图/模板不能取代该验收。

### 11.3 修订与续研

“核对这个结论”绑定原成果/断言，新回复保留关联；确认错误后发布新成果并说明影响，不覆盖旧消息、原业务记录或已导出文件。

“沿用原截止日复核”和“按新时点更新研判”分别呈现。新时点必须明确，沿用旧时点不借后来披露完善历史；换时点是关联旧成果的新执行，不用旧检查点换日期。新旧时期/口径不一致时分列，不能伪装可比。

成果差异只在对应研究/分支/时点内解释，不宣称“最新版本”替代所有历史判断。新建分支显示继承范围和上下文截点，明确发送前零模型/工具调用，不迁入原队列、未决审批或检查点。

## 12. 导出、删除和历史管理

### 12.1 P12 导出

选择已保存成果版本和Markdown/CSV/XLSX适用格式，再由用户选路径；存在文件时说明覆盖对象，目标变化/无法核实时重新确认或重选。PDF不默认纳入。

| 阶段 | 用户反馈 | 保护/下一步 |
| --- | --- | --- |
| 准备输出 | “正在准备 v2 的CSV”，可取消 | 不先截断旧目标 |
| 写入/安全发布 | 真实阶段，不伪造精确百分比 | 发布前失败保旧；不能安全发布则拒绝破坏性降级 |
| 成功 | 明确版本、格式、实际路径 | 复制路径/关闭；不诱导再次研究 |
| 失败/清理残留 | 说明磁盘/占用/权限或生成错误，以及本次残留 | 保留预览；只清理归属可证的临时输出，不误删他人文件 |
| 结果未知 | “文件可能已写入，需核对” | 只读核实；不盲目再覆盖 |
| 重试导出 | 明确同一已保存版本及当前路径/确认 | 零新增模型/外部工具/查询；资料不可得不暗换最新或重算 |

取消先于发布则不发布；发布先完成就显示实际完成，不假称回滚。研究成功与导出失败可同时显示，两者不互相覆写终态/费用；重启不自动重新导出。

### 12.2 P13 删除

预览分“将删除”“受影响引用”“仍会保留”，列出主子记录、受管附件/成果/索引/摘要；不能只有“确定删除吗”。

- 源被未结束研究、排队、等待/中断/需核实或正在导出引用时阻删，给具体对象及返回入口；不自动终止或改写B。
- 只有非活动引用时，确认后清理源及受管派生副本；其他研究保留最小“来源已删除”关联，不能隐式保留源正文以假装可追溯。
- 其他会话自有消息/成果中的摘录、独立资料和外部导出仍在，预览说明分别怎样清理；不能宣称相关内容已全部抹除。
- 预览后引用范围变化重做预检；清理失败显示待完成范围，不从残留缓存把已删来源读成完整证据。

重命名/置顶/归档保主子关联；归档可检索不等于删除。历史/搜索缺模型、MCP不可用或摘要失败时仍能打开、定位和复制；索引滞后/错误不能显示“没有历史”。

## 13. 设置、默认 Prompt、Skills 与 MCP

### 13.1 设置组织与迁移

在现有“设置 → AI大脑”中复用模型连接/场景/使用记录三页签，新增“研究配置”分区入口：角色与提示词、Skills、MCP、授权说明。使用摘要行＋明确编辑面板，不在滚动区域里嵌套无界多层TabBarView。

从研究模型选择器跳设置须保留原草稿/资料，返回仍在原现场；保存连接不改旧队列或活动执行。既有深链仅使用现有合法协议，新增研究定位/编辑面板需显式扩展结构化请求与消费方，不能随手增加冒号段伪造可用路由。

股票Prompt优先级仍是策略自定义→内置策略→全局兜底及页面补充；迁移展示来源/版本和旧值。保留业务数学语义，旧编辑器与新编辑器不能形成双写源；聊天角色Prompt不套股票JSON，固定新闻场景Prompt保持独立。

### 13.2 各配置界面的状态

| 界面 | 内容/操作 | 失败与安全边界 |
| --- | --- | --- |
| P14 模型 | 唯一系统连接、能力/授权/适配状态、具体连接或场景默认、实际尝试/用量 | 未验证/不兼容与断连不同；不暗备，不新增Router，不把保存当已获授权 |
| P15 角色/Prompt | 主/子角色选择，默认模型继承/显式覆盖，默认/自定义/实际合成来源与版本；预览、保存/取消、恢复默认确认；教程相邻 | 来源未知保留，不凭同文覆盖；升级不丢自定义，Prompt不解除程序合约；当前原型的单主角色编辑不等于全部配置完成 |
| P16 Skills | 导入前来源/许可/内容；已安装/角色启用/主子分配分别表达；分配草稿保存/取消、手动选择与更新 | 取消勾选必须保存为实际分配变化；失败保旧、缺依赖说明；安装不运行脚本/装依赖/放权，活动版本保留/延后清理 |
| P17 MCP | 本地 stdio；远程 Streamable HTTP（推荐）/HTTP + SSE（旧版兼容）；新增/编辑/删除及鉴权引用；保存/启动/测试/鉴权/工具授权分别表达 | 删除影响预检及活动引用策略按 DI-02 确认，不删除共享凭据；远程无本地启动；身份/schema变更复核，未知不盲重 |
| P18 范围/费用 | 目标/用途/资料范围、有效期、撤销、账本入口 | 新附件/摘要/MCP资料不默扩旧授权；未知费用不当0，不能另造收费准入 |

模型连接测试只发送合成内容并取得适用单次确认；MCP启动/测试按其实际副作用取得必要许可，不把“测试”包装成业务数据使用授权。凭据不进入历史、摘要、索引、日志或导出。

启动参数一行一项，路径空格不拆分；环境/Header使用安全引用，不读取凭据值。保存、启动、连接、鉴权、发现、调用授权分列，切服务/协议保未保存草稿；远程无本地启动，旧SSE消息端点由协议发现，不自动切协议。超时按详细设计§9.1的1—120秒，不沿用旧演示参数。

## 14. 用量、费用与缺配置反馈

主会话只显示本轮/累计摘要，详情列主/子/摘要及逐次实际尝试。框架重试不能隐藏，重试不清零费用，未实际使用的候选不算实际调用。

| 情形 | 文案语义 | 后续 |
| --- | --- | --- |
| 已计价/确知免费 | 实际已计价金额或明确免费及计量依据 | 继续遵既有预算/限额 |
| 合法仅计用量 | “金额未统计/不可计价”，用量仍可见 | 沿原治理准入，不因未知金额一律拒绝 |
| 确定到限 | 显示受限项、现场保留及设置入口 | 停受限新派发，不拆任务绕限 |
| 授权/预算/账本读取失败 | 明确治理不可确认，显示失败/待核实 | 不把读取错误降级成合法usage_only放行 |
| 无模型/能力不足 | 具体缺条件和原系统设置入口 | 历史/复制/教程仍可用，不暗装或切连接 |

金额未知不能显示“¥0.00”；没有账本结果不能把累计量标0；正文“已完成”不是保存或计费事实。

## 15. 输入、可访问性、主题和文案

### 15.1 键盘与焦点

- 全部操作有文本入口或具tooltip的图标；危险操作有明确对象/影响；右键/悬停/双击仅是加速入口。
- 原Ctrl+1—7与Ctrl+F语义保留；研究搜索有可见按钮，可提议Ctrl+Shift+F作为局部加速键，但需验证无冲突后启用。
- 多行输入、IME、弹框Enter/Esc、Tab顺序按真实Flet验证；Esc/关闭不批准。必要决定旧输入事件隔离，不靠“阻止默认事件”文字当实测证据。
- Tab顺序与视觉阅读顺序一致；打开详情/子会话/结果后给可辨识标题，返回恢复合理焦点。
- 局部选择覆盖正文、工具公开文本、代码块和表格；整条复制只是补充。流式重渲染不得丢选区。

### 15.2 主题与可读性

颜色使用 `AppColors` 语义，字号使用 `AppStyles.FONT_SIZE_BODY/TITLE/XL/CAPTION` 等；间距使用 `SPACING_*`。涨跌红绿与成功/失败不是同一维度，状态必须附文字/图标。

普通正文沿用14、小号13、辅助12的现有token层级，不用缩小字解决空间不足。Dark/Light/Navy/Dracula及中英文/文本缩放均有验收；具体对比度、label、Dialog关闭与Toast最低时长以无障碍正本为准，不另设较低标准。

### 15.3 常用状态文案

| 不用 | 使用 |
| --- | --- |
| 已停止（点击后立即） | 中断请求已受理，等待安全边界 |
| 无风险/无数据（读取失败） | 当前资料不足/读取失败，不能据此判断 |

## 16. 跨场景错误与恢复矩阵

| 故障/边界 | 用户可见信息及可用下一步 | 必须保留/禁止 |
| --- | --- | --- |
| 请求提交未知 | 正在核对提交；查原身份 | 草稿/受理关联，不换身份重复提交 |
| 原资料变更/被删 | 原版本不可用，选择并确认新资料 | 不默换最新；P13显示影响 |
| 解析部分/超限 | 实际已读范围及未读项；分批/移除/预处理 | 不把少量读取当全量 |
| 模型/工具超时、断连 | 区分失败、未知和等待；核对后可用动作 | 不重复非幂等未知副作用，不暗回旧链 |
| 一叶失败/一叶等用户 | 各自状态和真实依赖；主会话精确控制 | 无关分支继续，有效成果/费用保留 |
| 输出合约错误 | 解释不合格边界及已有有效部分 | 工具中间轮不误进最终JSON校验，不把非法最终结果保存为成功 |
| 摘要/存档失败 | 压缩失败/超预算/未保存分别说明 | 原文可查，历史读路径不触发摘要，不清草稿 |
| 事件丢失/乱序 | 核对权威状态；暂不可确认明示 | 不回退终态、不重执行工具补消息 |
| 设置保存/迁移失败 | 字段或页内错误与原值/当前有效来源 | 旧有效配置和未知来源保留，不双编辑源 |
| 导出/删除失败 | 独立操作状态、残留/待完成范围 | 不重跑研究、不误删，不假完成 |
| 退出/崩溃重启 | P24显示旧历史、未结束/需核实及可靠继续边界 | 应用关闭后不继续，重启/浏览不派发 |

- 服务目录/详情提供“删除此服务…”入口，确认框显示服务身份/版本、角色默认及队列/执行引用、本地进程/连接与在途操作、将移除的配置/鉴权映射和仍保留的历史。取消不改变配置或连接，不默认选择危险操作。
- 采用已确认的[需求 DI-02](./AGENT_REQUIREMENTS_SCENARIO_v1.4_2026-11-03.md#162-%E7%A1%AE%E8%AE%A4%E6%B8%85%E5%8D%95)：有角色默认、排队/活动引用或在途操作时阻删并提供定位/解除路径；已有本地进程/连接先明确停止/断开并核对，再重新预检。策略已确认但尚未交付，此次确认不使真实删除可执行，不能据本稿隐式结束任务或杀进程。
- 预检到提交之间引用变化或事实未知，旧确认不生效，展示变化并重新核对。无引用且获适用确认后仅删除该服务配置与本服务鉴权映射，不删除共享Keyring条目、环境变量或其他服务引用；历史标注服务配置已删除，同名重建不继承原批准。
- 远程不出现“启动本地进程”；断开连接不声称关闭远端服务。停止/断开失败或未知有独立状态，不假称已清理。
- **验收：** 删除前取消后服务/配置不变；实现已确认的DI-02后，有引用时不能提交删除，解除/停止并重新预检后才可确认。删除成功只影响目标服务，其他服务共享凭据引用及历史仍可查；插入新引用须使旧确认失效。关联 F14/F15/F24、S00/S05/S07、AC11/AC20/AC32。

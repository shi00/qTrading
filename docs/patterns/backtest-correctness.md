## 正确性的四要素

结论会**失真而不报错**，只有四类偏差会同时满足「不报错」与「系统性」：取数时点、票池构造、复权口径、财报修订。任何一条回测/选股结论，都应由这四问自检。

### 1. 时点正确性（Look-ahead / 前视偏差）

**判据**：任何进入策略或回测的数据，其**取数时点不得晚于被决策的交易日**。使用「当前快照」类维度（行业分类、指数成分、股票池、财报最新值）参与**历史区间**计算即违规——必须改用带生效日期的维度表，或显式声明为「当期近似」并在结果中标注。

- 正确做法：按 `as_of` 时点做 PIT（point-in-time）过滤；财报按 `ann_date <= trade_date` 约束；存活判定用「退市日晚于 as_of」而非「今天是否在市」。
- 反面样本：`sw_industry_member`（申万行业成员）主键不含日期，是**全局快照**；用**今天**的行业归属去回测若干年前，跨分类调整期即前视（详见下方「已知限制」DAT-08）。
- 自动守护：R24（报告模式，`check_redlines.py::check_R24`），扫 `strategies/` 下对无生效日期维度表/ORM 类/派生列键的引用，输出 warning 提示人工确认取数时点；语义与升级期限见 [ruleset-changelog.md](../governance/ruleset-changelog.md)。

### 2. 幸存者偏差（Survivorship Bias / 票池构造）

**判据**：回测票池必须包含当时**已退市/后来退市**的股票，且必须按 `list_date <= trade_date` 排除**当时尚未上市**的股票。

- 只用「今天的在市股票」回测历史 = 幸存者偏差：绩效被系统性高估（失败者已被剔除）。
- 具体口径：区分**退市**与**临时停牌**——退市按最后已知价清算，停牌保留持仓（`BacktestDataProvider.get_stock_meta` 用 `delist_date` 判定）。
- 自检：票池 SQL 是否只按当前 `list_status` 过滤？是否漏用 `delist_date`？

### 3. 复权口径（Adjustment / 前复权 vs 后复权）

**判断**：跨期收益计算必须使用**同一复权口径**，且口径变更必须显式记录。

- **前复权（qfq）**：以当前价为基准回推，**历史价会随后续除权除息变化**——同一条回测在不同日期跑，历史价不同，结论不可复现。
- **后复权（hfq）**：以上市价为基准前推，历史价稳定，适合跨期收益与回测。
- 未复权价（raw）适用于市值/成交额类截面，不适合跨期收益率。
- 自检：本次结论用的是哪种口径？跨期收益是否混用了前复权与未复权？

### 4. 财报修订（Restatement）

**判断**：财报可能被**重述**（restatement），本项目的 `financial_reports` 主键为 `(ts_code, end_date)`、无修订历史，重述时**新值覆盖旧值**，库里只保留「今天所知的版本」。

- 产品含义：基本面类回测**不可复现**——历史回测结论会随时间漂移（同一区间，今天跑与半年前跑可能不同）。
- 缓解：回测报告 UI 摘要已显式标注「基本面数据为最新修订版」；不要在文档/UI 中把基本面回测结果表述为「可精确复现」。详见下方「已知限制」DAT-07。

## 哪些指标在什么条件下不可信

| 指标类别 | 不可信条件 |
|---------|-----------|
| 基本面类收益 / 财务因子 | 财报无修订历史（DAT-07）；跨期回测结果随时间漂移 |
| 行业中性 / 行业轮动 / 行业分散度 | 行业维度为当前快照（DAT-08②）；跨分类调整期存在前视 |
| 含退市股的高收益 | 票池未纳入当时退市股（幸存者偏差）→ 绩效被高估 |
| 跨期收益率 | 复权口径不一致 or 混用前复权与未复权 |
| 带缺口的区间结论 | 回测区间存在缺失交易日（数据质量门控被回测代理绕过，BT-05）→ 缺口日无信号，区间质量未反映 |

> 通用原则：**任何「更漂亮」的回测曲线，先怀疑它是不是偏差的产物**。单位错 100 倍会被一眼看出（R20），但前视/幸存者/复权偏差会安静地产出一条好看的夏普率——后者更危险。

## 已知限制（结论可信度边界）

> 以下条目是**已知的结论可信度边界**，不是待修的代码欠债；决策与缓解记录以 [docs/debt/known-technical-debt.md](../debt/known-technical-debt.md)「已接受的权衡」为准（本文只给产品含义）。

- **DAT-07 回测不可复现（财报修订）**：`financial_reports` 无修订历史，UPSERT 覆盖使历史回测结果随时间漂移。决策：不修（YAGNI，影子表成本高）。缓解：回测报告 UI 摘要显式标注「基本面数据为最新修订版」。
- **DAT-08② 回测前视（申万行业快照）**：`sw_industry_member` 为全局快照（对应 `index_member_all`），主键不含日期；申万分类整体调整时，跨调整期回测会把「当时不属于该行业」的股票算进去，影响行业中性/分散度上限/行业轮动类策略。决策：不修（申万成分历史需额外接口与配额）。缓解：回测报告 UI 摘要显式标注「行业分类为当前快照，跨调整期可能存在前视」。
- **DAT-08③ 存量污染（`industry_tushare`）**：早期同步曾把 `stock_basic.industry` 覆写为申万二级行业名，存量行在下次全量同步前可能显示申万值。决策：不单独回刷（全量同步即自愈路径）。
- **BT-05 回测质量门控绕过**：回测代理 `_BacktestQualityProxy` 硬编码 `QualityTier.GOLD`，使历史数据（含缺失日/异常值/未复权段）不反映数据质量问题，策略 `required_quality_tier` 声明在回测路径形同虚设。第二步（实现 `evaluate_historical_window()` 区间质量评估、低质区间以 `DataWarning` 显式告知而非拒绝执行）实施前，**带缺口区间的回测结论应视为「质量未核」**。

## 路由（必读 / 条件触发 / 完成判定）

### 必读

新增或修改回测/选股结论任务，至少阅读：

1. [CLAUDE.md](../../CLAUDE.md) §3.1 R24（时点正确性）、R20（单位未核对）、R21（缺失值伪装）与 §3.2（数据质量门控）
2. 本文件「正确性的四要素」与「哪些指标在什么条件下不可信」
3. [docs/guides/how-to.md](../guides/how-to.md) §7「新增回测配置」（配置流程正本）

### 条件触发

- 使用行业分类 / 指数成分 / 股票池 / 财报最新值参与历史区间计算 → 按「时点正确性」判断是否前视（R24）
- 涉及金额/数量列（`north_money` / `net_amount` / `amount` / `total_mv` / `circ_mv` / `vol`）的数值比较 → 经 `threshold_in_data_unit()` 统一入口换算后再比较（R20，见 [CLAUDE.md §3.1](../../CLAUDE.md)）
- 结论含基本面因子或基本面收益 → 按「财报修订」判断可复现性（DAT-07）
- 新增/修改策略 → 见 [docs/patterns/strategy-template.md](./strategy-template.md)

### 完成判定

- 取数时点：所有进入回测的维度数据满足「取数时点 ≤ 被决策交易日」，快照类维度已带生效日期或显式标注「当期近似」（R24）
- 票池构造：纳入当时在市/退市股，按 `list_date <= trade_date` 排除当时未上市股，退市与停牌分别处理
- 复权口径：跨期收益使用一致且显式的复权口径（qfq/hfq/raw 不混用）
- 结论标注：对受「已知限制」影响的指标（基本面/行业/质量未核区间），结论或报告 UI 显式标注不可信条件
- 单测：新逻辑经 `tests/unit/` 覆盖（按 [docs/guides/testing.md](../guides/testing.md) 模板编写）
- 最小验证命令：对照 [CONTRIBUTING.md](../../CONTRIBUTING.md)「变更类型 → 最小验证子集」该改动范围对应最小子集；另在提交前运行 `python scripts/check_redlines.py` 查看 R24 报告模式输出
